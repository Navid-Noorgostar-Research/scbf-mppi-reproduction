Independent reproduction & audit · arXiv:2206.11985

Path integral methods with stochastic control barrier functions

A from-scratch reproduction of Algorithm 1, on a curved-corridor unicycle and on the Solgenia harbour vessel — with the experiments the paper does not run, every finding checked against the literature, and the claims that did not survive marked as withdrawn. Everything below is served from the repository itself.

Interactive

Two browser applications, both offline and self-contained.

2-D bench The safety bench Both scenarios live, controllers racing side by side, with seven instrument panels: the row the filter works on, whether any Gaussian can satisfy it, the log density ratio split into its three parts, the ESS budget, the intervention penalty, whether a row violation is really a collision, and whether a defensive mixture recovers the target. 3-D viewer The runs in three dimensions One offline HTML file (Three.js, vendored) drawing the same runs as the figures — harbour water, the hull, the barrier surfaces. Nothing here changes an experiment: every drawn quantity is the 1-second state log of an exported run, and the 30-seed statistics in the titles are read from the stored result files.

Run it

# serve this page, the bench and the 3-D viewer, from the repository root
python -m http.server 8011          # any free port
# then open http://127.0.0.1:8011/

# the test suites
python -m scbf_mppi.selftest                  # corridor
python -m scbf_mppi.vessel.selftest           # vessel
python tests/test_regression.py check         # 12 shipped cases, bit for bit

# the measurements behind the findings
python tests/certificate_conservatism.py --seeds 64 --kind mppi   # CUDA
python tests/mixture_recovery.py
python tests/renyi_safe_gaussian.py --closed-loop                 # CUDA
python tests/logratio_decomposition.py
python tests/gpu_closed_loop.py --seeds 512                       # CUDA
python tests/timing_deadline.py                                   # ~20 min

# rebuild the browser applications from their sources
python live_demo/build.py
python live_demo/3d/build3d.py

# check every panel against the Python package
node live_demo/xval_certificate.js
node live_demo/xval_mixture.js

The CUDA scripts need CuPy and an NVIDIA device; everything else is CPU-only. REPRODUCIBILITY.md pins the versions and records what moved when they moved.

Corridor — the E series

The curved-corridor unicycle: reproducing the paper's own table, then the questions it does not ask.

E1Does Table I reproduce — as printed, and as corrected? E1The trajectories behind that table. E2Is the stated noise σ = I compatible with Table I? E3What Algorithm 1 costs in seconds — 10,000 SDPs per cycle. E4What probability the printed constraint actually delivers. E5Braking or steering? |v| and |ω| against distance to the wall. E7Do zero collisions at sample times mean the path stayed inside? E8Mean shift, variance reduction, or both — against deterministic MPPI at equal rollouts. E9Theorem 1 and the So–Clark–Fan counterexample, simulated. E11Other confidence levels — the exploration/safety trade-off. E12The printed barriers put the goal outside the safe set.

Vessel — the V series

The Solgenia, a 3-DOF Fossen model with second-order barrier rows, a 700 N azimuth force disk and a speed-dependent bow thruster.

V3White noise vs a 5 s gust vs gust plus unknown current. V4The crossing ferry. V4The crossing, second view. V5Wall-clock per control cycle. V6The barrier gains α₁, α₂. V7The confidence level δ. V8Deterministic MPPI — λ₀, ν and schedule sweep. V9The heading term the cost does not have. V10The barrier in the sampler, or on the output. V10bThe same, with the observer in the loop. V11The observer. V12The effective sample size the correction destroys. V14The deadline, which a median does not describe.

Data and source

  • results_shipped_2026_09_12/The frozen set the regression test reproduces bit for bit.
  • live_demo/The browser core (sim.js), the build script and every cross-validation harness.

  • tests/The measurement scripts: the certificate, the mixture, the sample-efficient Gaussian, the log-ratio split, the GPU closed loop, the deadline study.
  • scbf_mppi/The package itself — corridor, vessel, solver, the ESS budget, and the extensions.
