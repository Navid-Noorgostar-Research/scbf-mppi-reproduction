Path integral methods with stochastic control barrier functions

An independent reproduction and audit of arXiv:2206.11985 — corridor unicycle and Solgenia harbour vessel. Everything on this page is served from the repository itself.

Start here

The live demo → Both scenarios in the browser, controllers side by side, with the instrument panels: the row the filter works on, whether any Gaussian can satisfy it, the log density ratio split into its three parts, the ESS budget, the intervention penalty, and the certificate scored against what actually happened.

Run it

# serve this page and the demo (from the repository root)
python -m http.server 8000        # any free port; 8000 may be taken
# then open  http://localhost:8000/

# the test suites
python -m scbf_mppi.selftest              # corridor
python -m scbf_mppi.vessel.selftest       # vessel
python tests/test_regression.py check     # 12 shipped cases, bit for bit

# the measurements behind the findings
python tests/certificate_conservatism.py --seeds 64 --kind mppi    # needs CUDA
python tests/mixture_recovery.py
python tests/renyi_safe_gaussian.py --closed-loop                  # needs CUDA
python tests/gpu_closed_loop.py --seeds 512                        # needs CUDA

# rebuild the demo from its sources
python live_demo/build.py

The GPU scripts need CuPy and a CUDA device; everything else is CPU-only. REPRODUCIBILITY.md pins the versions and records what moved when they moved.
